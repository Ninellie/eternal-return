# View
Окончание View в названии класса свидетельствует о том,
что область ответственности этого класса концентрируется
вокруг работы с UI элементами, такими как текстовые
элементы, кнопки, изображения.
Это может быть логика отображения, интеракций, анимаций.

Обычно такой класс реагирует на события контроллера.

Влияние на контроллеры из элементов интерфейсов может быть 
обеспечена или через прокидывание действий из окна инспектора,
или с помощью влияния на контроллеры из View классов.
