Темы приносят мотивацию и являются основным элементом геймплея, держащим игрока в напряжении. У тем есть время жизни. Пока тема жива - в ней пишут пользователи.
# Создание тем
Чтобы создать тему игрок должен кликнуть на экран форуме и выбрать "Создать новую тему"
После создания темы в ней нужно написать сообщение.

### Очередь сообщений
На экране форума отображается интерфейс тем с сообщениями.

Тем может быть больше одной, но одновременно отображается только одна тема. Их можно менять горячими клавиши (1-9) или мышкой.
На экране отображается очередь сообщений в теме, на которые необходимо ответить. Самое старое сообщение уже выбрано. У игрока есть всего несколько секунд на ответ.

Каждое сообщение отображает текст сообщения, аватарку пользователя, код и поле для ввода ответа. 

Каждое сообщение является квик-тайм ивентом.

Когда сообщение появляется, оно издаёт звук. 

Чтобы ввести сообщение, нужно точно повторить код.

Код состоит из букв или цифр.

Доступны только WASD буквы и не более чем 5 символов.
У тем есть усложняющие мутации.

#### Мутации
- Интеллектуал: добавляются буквы QE + RF + ZXCV
- Многословность: размер не больше 9 символов
- Думай на ходу: изначально код не видел, его проигрывание можно запустить на пробел - тогда с быстрой скоростью будут показаны символы, а потом снова пропадут.
- Смайлопост: очень низкое время жизни, но символ всего один

Каждое создание темы имеет случайную кривую частоты появления сообщений.

# Награда
Каждое отвеченное сообщение приносит очки мотивации. За несколько сообщений подряд накапливается множитель стрика.
