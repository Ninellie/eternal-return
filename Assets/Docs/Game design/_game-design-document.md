Игрок управляет действиями Кексика - игрока с тревожностью, который сидит на форуме и изучает IT курсы.

Весь геймплей дня призван создать у игрока чувство стресса нарастающим количеством действий, которое нужно выполнять. Всё больше и больше. 
# Короткий цикл

День -> Ночь -> Следующий день
Периодически после ночи происходит событие.

# Обычный день
- Проснуться
- Создать тему
- Подумать над идеей
- Начать учить навык
- Параллельно отвечать на сообщения
- Подумать над идеей
- Завершить день
