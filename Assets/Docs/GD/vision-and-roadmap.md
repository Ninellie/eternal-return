# Видение и роадмап

Ревизия направления проекта, актуальна на 24.09.2026.

## Диагноз

Прототип реализует ~30-40% GDD: ресурсы, лайки, идеи, навыки, темы, стресс и выгорание частично на месте.
Не реализовано ровно то, что превращает механику из обычного инкрементала в рогалик: мини-игры,
сброс run, конвертация в продуктивность, прокачка/слияние навыков.
Жанр в GDD заявлен как "Рогалик", но пока играется как idle-кликер без ставок и без провала.

## Решение

1. **Тема — единственное реальное отличие проекта от тысяч других инкременталов.**
   Парень на форуме, курсы, стресс, выгорание, сгорание прогресса — это узнаваемая для аудитории
   разработчиков/студентов/фрилансеров ситуация. Усиливать через текст и подачу: флейвор-тексты,
   ироничные подписи ресурсов и событий, а не через визуальный полиш (на арт бюджета нет).

2. **Сокращение скоупа тем.** Три типа тем из GDD — избыточно для MVP. Оставить два:
   "Рассказать про день" (бесплатная, база) и "Дать обещание" (мини-игра, первая ставка в игре).
   "Объявить дневник" (HP, стрики) — после MVP, если тестирование покажет, что core loop держит интерес.

3. **Приоритет — ставки, а не контент.** Следующий спринт целиком на мини-игру "Борьба с
   прокрастинацией" и полный цикл стресс → мини-игра → выигрыш/поражение → выгорание → сброс run.
   Без этого не за что удерживать игрока дольше одной сессии.

4. **Движок.** Unity 6000.7.0a2 — альфа. Перед продолжением разработки перейти на актуальный
   стабильный релиз Unity 6 LTS. Риск нестабильности альфы не оправдан для соло-проекта на этой стадии.

5. **Дистрибуция.** Целевая площадка — itch.io, pay-what-you-want или дешёвый релиз (2-5$).
   Steam — только после арт-пасса и полного core loop. Мобильные площадки и реклама — не рассматривать,
   ресурсов на F2P-инфраструктуру нет и она не нужна для этого объёма контента.

## Порядок работ

1. Мини-игра "Борьба с прокрастинацией" (стресс = 100 → мини-игра → победа/поражение по GDD).
2. Мини-игра выгорания + сброс run + ресурс продуктивности.
3. Save/load хотя бы в PlayerPrefs — без этого тестирование убивает интерес на первом же перезапуске.
4. Прокачка навыков (уровень за мотивацию, слияние дублей → тир) — сейчас Skill статичен.
5. Расход мотивации на изучение идеи — механика есть в GDD, в коде отсутствует.
6. Второй тип темы ("Дать обещание") после того, как первый core loop подтверждён на тесте.
7. Лимит сокетов = 10 (сейчас не ограничен).
8. Только после пунктов 1-7 — арт-пасс и звук.

## Что не трогать сейчас

Темы 2 (частично) и 3, метапрогрессия за продуктивность, мультиплеер (не нужен, оставить как есть
неиспользуемым), мобильные платформы.
